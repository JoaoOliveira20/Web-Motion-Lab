# Frontend Lab — Direção de Arte

## Conceito

Experimental digital studio / interactive technology laboratory.

A interface deve parecer criada por um estúdio especializado em experiências digitais, e não por um template genérico de SaaS.

## Estética

- editorial
- experimental
- tecnológica
- minimalista
- tipografia forte
- grid rígido
- espaço negativo
- contraste
- movimento intencional

## Paleta

Base predominantemente neutra.

Utilizar uma cor de destaque com moderação.

Evitar excesso de cores simultâneas.

## Tipografia

Priorizar:

- títulos grandes
- contraste de escala
- labels pequenos
- tipografia monoespaçada para informações técnicas
- hierarquia clara

## Layout

Utilizar:

- grid
- margens generosas
- alinhamentos consistentes
- seções com identidade própria
- whitespace

## Movimento

As animações devem:

- comunicar hierarquia
- orientar o olhar
- demonstrar tecnologia
- reforçar transições
- possuir timing intencional

Evitar animações sem propósito.

## Evitar

Não usar automaticamente:

- glassmorphism
- neon
- purple gradients
- glow exagerado
- blobs
- cards genéricos
- excesso de sombras
- dashboards SaaS
- efeitos aleatórios
- dezenas de elementos flutuando

## Hero

O Hero deve demonstrar uma ideia central do laboratório.

Possível composição:

- headline grande
- pequena identificação técnica
- elemento interativo
- movimento controlado
- indicação de scroll

## Seção de experimentos

Cada experimento deve apresentar:

- nome
- biblioteca
- objetivo
- demonstração
- nível de complexidade
- pequena explicação

## Showcase final

A página final deve parecer uma experiência coerente.

Não tentar demonstrar todas as bibliotecas simultaneamente.

Selecionar apenas as ferramentas que contribuem para a experiência.

## Regra visual

Se um efeito poderia existir sem nenhuma razão, remover.

Se uma animação não melhora a experiência, remover.

Se uma biblioteca estiver sendo usada apenas para adicionar um efeito aleatório, remover.

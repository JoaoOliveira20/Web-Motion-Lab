## Perguntas obrigatórias

Para cada biblioteca, responder:

1. Qual problema ela resolve?
2. Qual é o modelo mental da API?
3. Qual é o menor experimento útil?
4. Qual é o maior benefício?
5. Qual é a principal limitação?
6. Qual impacto ela pode ter na performance?
7. Ela exige Client Component?
8. Como lidar com SSR/hydration?
9. Qual alternativa existe?
10. Em qual situação eu escolheria outra ferramenta?

## Critério de domínio

Marcar uma biblioteca como dominada somente depois de:

- experimento isolado
- implementação sem tutorial
- integração com Next.js
- revisão
- teste
- comparação com alternativa
- documentação do aprendizado
